[디지털배지 학생 안내 페이지 - 게시 요청 파일]

1. 구성
   - index.html : 페이지 본문 (글꼴 포함, 별도 글꼴 설치 불필요)
   - img/       : 페이지에 쓰이는 이미지 (index.html과 같은 위치에 폴더째 업로드)

2. 게시 방법
   - 폴더 구조를 그대로 유지한 채 웹서버에 업로드
   - 서버 측 프로그램(DB, PHP 등) 불필요, 정적 파일만으로 동작

3. 희망 주소 (예시)
   - www.yuhan.ac.kr/badge  또는  badge.yuhan.ac.kr

4. 외부 링크
   - 유한대학교 홈페이지, 포털, 레코스 오픈배지 지갑, 레코스 수령 가이드(노션)
